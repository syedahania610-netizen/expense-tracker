# Ledger — Minimalist Expense Tracker

A modern, fast, and minimalist expense tracking web application built with **React**, **TypeScript**, and **Tailwind CSS**. Designed for effortless daily logging, dark mode aesthetics, real-time analytics, budgeting, and recurring subscription tracking.

## ✨ Features

- **⚡ Rapid One-Line Entry**: Log expenses and income in seconds with automatic category prediction, quick amount presets (+$5, +$10, +$25, +$50, +$100), payment methods, and tags.
- **🌓 Sophisticated Dark Mode & Theme Engine**: Auto-detects system preferences with instantaneous toggle (`T` hotkey) and persistent storage.
- **📊 Real-Time Visual Analytics**: Interactive category breakdown donut charts, 14-day daily velocity and burn rate bar charts, and top expense merchant insights.
- **🎯 Dynamic Budgeting & Daily Allowance**: Set category and overall monthly budget caps. Automatically calculates safe daily allowances and pacing indicators based on days remaining in the month.
- **🔄 Recurring Subscriptions Tracker**: Track active subscriptions, upcoming renewal dates, monthly overhead, and annualized fixed costs.
- **💾 100% Client-Side Privacy & Export/Import**: Data persists securely in browser storage. Export or import in CSV spreadsheet and JSON backup formats anytime.
- **⌨️ Keyboard-First Power Shortcuts**:
  - `N`: Quick Add focus
  - `/`: Search & Filter focus
  - `T`: Toggle Theme
  - `1`, `2`, `3`, `4`: Tab navigation
  - `E`: Export / Backup modal
  - `?`: Shortcuts cheat sheet
  - `Esc`: Close active modal

## 🚀 Quick Start (Local Development)

1. **Clone the repository**:
   ```bash
   git clone https://github.com/syedahania610-netizen/expense-tracker.git
   cd expense-tracker
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) (or the port specified by Vite) in your browser.

4. **Build for production**:
   ```bash
   npm run build
   ```

## 🌐 Deploy to Vercel in 1-Click

1. Visit [Vercel](https://vercel.com/new).
2. Click **Import Git Repository** and select `syedahania610-netizen/expense-tracker`.
3. Keep default settings:
   - **Framework Preset**: Vite
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
4. Click **Deploy**!
